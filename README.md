### Hi, I'm Rhyker 👋

I'm a computational biologist and software engineer at [TGen](https://www.tgen.org) in the [Barthel Lab](https://github.com/barthel-lab). I build reference-free, k-mer-based tools for characterizing complex genomes directly from sequence. Before TGen, I did my PhD at Johns Hopkins in the [Schatz Lab](https://github.com/schatzlab).

#### Tools

| | |
|---|---|
| **[KaryoScope](https://github.com/barthel-lab/KaryoScope)** | Alignment-free annotation of repeats, genes and other genomic elements in long reads and assemblies, at base-pair resolution, in minutes. Resolves centromeres, subtelomeres and acrocentric short arms across the HPRC Release 2 pangenome. *Lead developer.* [bioRxiv 2026](https://doi.org/10.64898/2026.05.15.725544) |
| **[GenomeScope 2.0](https://github.com/tbenavi1/genomescope2.0)** | Estimates genome size, heterozygosity and repeat content at any ploidy from the k-mer spectrum of raw reads. Cited 3,000+ times and a standard first step in assembly workflows. *Creator.* [Nat Commun 2020](https://doi.org/10.1038/s41467-020-14998-3) |
| **[Smudgeplot](https://github.com/KamilSJaron/smudgeplot)** | Infers ploidy and genome structure from pairs of heterozygous k-mers. *Co-developer.* [Nat Commun 2020](https://doi.org/10.1038/s41467-020-14998-3) |
| **[SVCollector](https://github.com/fritzsedlazeck/SVCollector)** | Picks the samples that capture the most structural-variant diversity for long-read resequencing, using a greedy heuristic and an exact ILP. *Lead author.* |
| **[karyozip](https://github.com/AndreaGuarracino/karyozip)** | Lossless columnar storage for k-mer annotation tracks (`.kst`), written in C and Rust. *Core contributor.* |
| **[HKS](https://github.com/jnalanko/HKS)** | Hierarchical k-mer sets in Rust, the lookup engine behind KaryoScope. *Contributor.* |
